# keyboard.wtf Chrome Helper — Store listing

## Name

keyboard.wtf Chrome Helper

## Summary

Lets Jarvis safely read and act in Chrome tabs when you request browser automation.

## Category

Productivity

## Language

English

## Detailed description

keyboard.wtf Chrome Helper connects the keyboard.wtf Windows assistant to the
Chrome tabs you choose to automate.

When you ask Jarvis to perform a browser task, the helper can read relevant
visible page state, show which tab is being controlled, highlight the exact
target, and carry out the requested navigation, clicking, typing, form filling,
or page reading in your existing Chrome session.

The helper:

- Uses your existing Chrome window and signed-in session.
- Remains idle until keyboard.wtf starts an explicit browser task.
- Shows a small in-page control indicator during a task.
- Highlights the exact live control immediately before an action.
- Keeps useful tabs open when a task finishes.
- Supports pause, resume, and cancellation from keyboard.wtf.
- Stops for passwords, one-time codes, CAPTCHAs, payment, checkout, banking,
  and account-security steps.
- Contains no advertising, analytics SDK, or tracking service.
- Lets the official keyboard.wtf website show Connected only after a live,
  status-only handshake with the local Jarvis app.

The keyboard.wtf Windows app must be installed and running for this extension
to connect and operate.

## Single purpose

Connect the keyboard.wtf Windows assistant to user-authorized Chrome tabs so
Jarvis can read visible page state and execute explicitly requested browser
actions in the user’s existing Chrome session.

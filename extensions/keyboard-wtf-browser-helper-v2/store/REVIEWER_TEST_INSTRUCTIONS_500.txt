Install keyboard.wtf for Windows from https://github.com/UnknownGod2011/keyboard.wtf/releases/download/v1.3.0/keyboard-wtf-setup.exe and launch it. Install this extension. In Settings > Browser Automation, select Retry / reconnect. Open https://en.wikipedia.org/wiki/Alan_Turing and select Check connection status. Ask Jarvis "What is on this page?" The existing tab is used and a control badge appears. Ctrl+Alt+X cancels. No account or test credentials are required.

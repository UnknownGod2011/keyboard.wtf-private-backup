Install keyboard.wtf 1.4.5 from https://github.com/UnknownGod2011/keyboard.wtf/releases/download/v1.4.5/keyboard-wtf-setup.exe and launch it. Install this update in the existing Store item. In Settings > Browser Automation, click Retry / reconnect. Open https://en.wikipedia.org/wiki/Alan_Turing and click Check connection status. Confirm Connected and ready with protocol 2.1.21. No extension account is required; AI browser tasks require an active app entitlement.

Help for the private staging system

Support

Sign-in

For the website, choose Sign in with Google on the Account page. For desktop pairing, start sign-in from the staging Jarvis candidate, complete Google sign-in in the system browser, and approve the one-time connection. If the request expires, close the page and start again.

Credits and checkout

New accounts have zero usable credits. Audited staging credits may be granted by an authorised staging administrator, or Razorpay Test Mode can be used after sign-in is approved for testing. A checkout remains pending until the backend verifies the server event.

Devices

Use Account & Billing to revoke a device. Revoked desktop sessions must sign in again.

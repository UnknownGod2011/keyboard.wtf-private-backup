Help with keyboard.wtf

Installation, Chrome Helper connection, API setup, restart, uninstall, and practical troubleshooting for the Windows app.

Install or update

  1. Download the latest Windows installer from the official GitHub Release.
  2. Run keyboard-wtf-setup.exe. The per-user installer does not require an administrator account.
  3. If Windows SmartScreen appears, confirm that the file came from the official keyboard.wtf GitHub repository before continuing.
  4. The installer updates an older keyboard.wtf installation in place, preserves local settings, and registers startup for the current Windows user.
  5. On first launch, Settings opens so you can finish Gemini API and speech-model setup.
The beta installer is not yet code-signed. Download it only from this site or the official GitHub Release.

Set up Gemini

  1. Open keyboard.wtf Settings with Ctrl + Alt + ,.
  2. Choose Set API Key, get a key from Google AI Studio, paste it into the password-style field, then select Save & test.
  3. The key is encrypted for the current Windows account. It is not sent to the keyboard.wtf website.

Connect the Chrome Helper

Recommended: Chrome Web Store

  1. Install keyboard.wtf Chrome Helper from its Chrome Web Store page when the listing becomes available.
  2. Keep keyboard.wtf running, open a normal HTTP or HTTPS page, then open Settings → Browser Automation.
  3. Select Retry / reconnect, followed by Check connection status.
  4. Connected and ready means the service worker, page helper, local Native Messaging host, and current tab all agree.

Fallback: unpacked helper

If Store installation is unavailable, Settings can prepare the included unpacked helper. Open chrome://extensions, enable Developer mode, choose Load unpacked, and select the folder opened by keyboard.wtf.

Do not enable both helpers at once. The unpacked route is a troubleshooting/development fallback and does not receive normal Chrome Web Store updates. keyboard.wtf deliberately blocks browser commands if both identities are active.

Restart keyboard.wtf

Open Settings → Support & maintenance and select Restart keyboard.wtf. The app cancels active work, releases hotkeys and the browser bridge, exits, and launches one fresh instance. Chrome and its tabs remain open.

If Settings is unavailable, exit keyboard.wtf from its system-tray icon and launch it again from the Start menu.

Uninstall

Use Settings → Support & maintenance → Open Windows uninstaller, or open Windows Settings → Apps → Installed apps → keyboard.wtf → Uninstall.

The in-app option lets you preserve local settings and memories for reinstall, or request their removal. Windows asks for confirmation before the registered uninstaller proceeds.

Troubleshooting

  • Shortcut does not respond: open Settings, check the active-hotkey status, and reset or change any shortcut occupied by another app.
  • Chrome Helper is not ready: open a normal webpage, disable any duplicate helper, choose Retry / reconnect, then Check connection status.
  • Browser task is stuck: press Ctrl + Alt + X. Chrome stays open and later actions are cancelled.
  • Manual step required: complete passwords, OTPs, CAPTCHAs, payment, checkout, banking, or account-security steps yourself, then resume only when safe.
  • Timer or Jarvis appears frozen: use Restart keyboard.wtf. Active timers and browser tasks are intentionally cancelled during restart.
  • API error: verify the configured Gemini key, quota, and internet connection in Set API Key.

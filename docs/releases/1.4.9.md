# keyboard.wtf 1.4.9

keyboard.wtf 1.4.9 is a narrow browser-task lifecycle reliability update.

- A task paused for login, CAPTCHA, confirmation, permission, ambiguity, or
  another manual step now retains and reports the exact intervention reason.
  The user can complete the step and say continue to resume the same task, or
  cancel it cleanly.
- If the one task-owned tab disappears during navigation, the desktop performs
  one bounded recovery through the existing published Helper and opens the
  intended safe HTTPS destination without replacing an unrelated active page.
- A spoken browser-task cancellation now has one user-visible acknowledgement:
  the tool result remains authoritative and the duplicate background terminal
  announcement is suppressed for that same cancellation only.

The existing New Tab bootstrap, normal-tab target selection, Jarvis Live,
Smart Writing, Screen Reasoning, authentication, billing, provider routing, and
usage settlement are unchanged.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

# keyboard.wtf 1.4.8

keyboard.wtf 1.4.8 is a focused browser-automation reliability update.

- Jarvis browser tasks may now bootstrap from a disposable Chrome or Edge New
  Tab through the authenticated Helper service worker, navigate that same tab
  to a safe HTTPS destination, and continue without asking the user to repeat
  the command.
- Meaningful browser-internal pages, stale Helper heartbeats, incompatible
  protocols, unrecognized extension identities, and multiple competing Helpers
  remain blocked.
- Existing target selection for normal websites is unchanged, so an unrelated
  meaningful page is preserved and an already-open target remains reusable.

Jarvis Live, Smart Writing, Screen Reasoning, account authentication, billing,
provider routing, and usage settlement are unchanged.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

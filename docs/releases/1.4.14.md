# keyboard.wtf 1.4.14

keyboard.wtf 1.4.14 is a narrow selected-context and Smart Writing quality update.

- Incremental Jarvis voice transcription no longer eagerly starts Browser
  Automation for an incomplete answer, solve, or explain fragment that may
  still resolve to selected text. The completed Live turn remains
  authoritative: explicit fill, click, submit, page-mutation, and explicit
  Browser Automation requests continue to use Browser Automation normally.
- Smart Writing now asks Gemini to perform a full speech-to-writing editorial
  cleanup rather than a near-verbatim transcription. It removes meaningless
  fillers, accidental repetition, abandoned false starts, and awkward spoken
  syntax while preserving meaning, tone, names, technical terms, URLs,
  numbers, details, and intentional emphasis.
- Smart Writing settlements now retain their existing server-owned model route,
  pricing, reservation, and idempotency behavior while recording the distinct
  authoritative activity label `smart_writing`, so Recent Usage no longer
  presents these requests as Selected Text.
- The Settings sidebar derives its order from the rendered section order. Voice
  Capture now consistently precedes Account & Billing, and the local filler
  checkbox explicitly states that Smart Writing's Gemini editing is independent.
- Fully settled itemized usage details receive a Firestore TTL timestamp thirty
  days after the relevant cycle end (or settlement when no later cycle end is
  available). Account totals, allowance buckets, ledger, reservations,
  idempotency, payment, subscription, and reconciliation records never receive
  this TTL.

Raw Dictation, Gemini Live lifecycle and rollover, Screen Reasoning, Chrome
Helper 2.1.25, workflows and durable memory, file search, authentication,
billing math, pricing, reservations, settlement, and updater security are not
redesigned by this patch.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

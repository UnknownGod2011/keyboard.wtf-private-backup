# keyboard.wtf 1.4.4

keyboard.wtf 1.4.4 is a focused Windows overlay reliability update.

- The shared Jarvis, Smart Writing, and Dictation overlay now creates and owns
  its native window handle on the application's UI thread before background
  account, provider, browser, or diagnostic work can publish status updates.
- Background status updates are marshalled to that established UI handle. A
  shutdown race now drops only the best-effort visual update instead of
  surfacing a raw Microsoft .NET window-handle error.
- Jarvis continuity, Smart Writing's bounded terminal states, billing,
  authenticated usage metering, hotkeys, and Chrome Helper protocol behavior
  are unchanged from 1.4.3.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

# keyboard.wtf 1.4.7

keyboard.wtf 1.4.7 is a focused clean-install and Jarvis start/stop reliability
update. It preserves the established Gemini Live conversation, Smart Writing,
screen, browser, authentication, and billing behavior.

- Public release packaging now proves that the distributable is the normal
  paid-production product, with Account & Billing enabled and emergency BYOK
  hidden for a fresh user.
- A first installation opens a concise Getting Started page with the actual
  Smart Writing, Raw Dictation, and Jarvis shortcuts from the user's settings.
  Ordinary restarts no longer reopen onboarding.
- The website's primary Windows buttons share one canonical release URL and
  start the installer download directly; the navigation Download link still
  scrolls to the platform section.
- Ending Jarvis no longer holds the Live lifecycle lock while a post-settlement
  account refresh waits on the network. Later shortcut presses therefore cannot
  queue behind an unrelated account timeout.
- Read-only account requests no longer rewrite unchanged Firebase profile data.
  Bounded Firestore contention retries preserve existing transaction and
  idempotency guarantees for account identity and reservation release.

Jarvis still connects to Gemini Live immediately when invoked, keeps one logical
session across recoverable physical socket rollover, and ends only through the
existing user-controlled paths. Provider-authoritative accounting, pricing,
allowances, and payment behavior are unchanged.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

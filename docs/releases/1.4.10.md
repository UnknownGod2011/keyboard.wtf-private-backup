# keyboard.wtf 1.4.10

keyboard.wtf 1.4.10 is a focused intelligence and operation-lifecycle reliability update.

- Smart Writing now keeps the final Gemini result on the clipboard even after
  successful insertion. Operation ownership prevents a cancelled or replaced
  request from pasting late or overwriting the active overlay, while explicit
  stopping and long natural recording pauses remain unchanged.
- Jarvis automatically performs bounded recovery when a previous Live session
  slot is still being finalized by the service. Resetting or changing a hotkey
  is never required to restore the connection.
- Bounded local file search now extracts the intended name from natural phrases,
  handles spaces, underscores, hyphens, and case more reliably, and reports the
  containing folder for safe navigation.
- Safe email and message drafts prefer existing deterministic draft tools instead
  of starting browser automation in parallel. Final successful tool receipts are
  authoritative over superseded internal failures.
- Explicitly saved routines remain persistent, one-time commands remain transient,
  and deleting a routine by a learned alias now also removes and tombstones its
  canonical saved workflow so stale routines cannot return.

Jarvis's immediate Live startup, continuous logical session and socket rollover,
Smart Writing Gemini-audio understanding, Screen Reasoning, Chrome Helper protocol,
authentication, billing, provider pricing, reservations, and settlement are not
redesigned by this release.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

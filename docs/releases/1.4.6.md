# keyboard.wtf 1.4.6

keyboard.wtf 1.4.6 is a focused Jarvis intent and protected-tab reliability
update. It deliberately preserves the established Live, Smart Writing, screen,
authentication, and billing architecture.

- Unqualified Settings requests now open Windows Settings, while explicit
  keyboard.wtf/Jarvis Settings requests use the running local Settings service
  and its canonical section routes.
- Explicit requests to launch an app or application prefer a genuinely
  installed Windows application instead of silently substituting a website.
- Jarvis validates session termination against the user's current words.
  Browser/window close commands and conversational thanks keep Jarvis active;
  explicit goodbye, stop-Jarvis, and end-chat requests still end it.
- Natural questions about the current visible screen are routed to a fresh
  one-shot image analysis rather than a shallow foreground-app answer.
- Chrome Helper 2.1.24 can lease a protected or blank active tab without
  injecting into it, navigate that same tab to a planner-selected safe HTTPS
  destination, and then continue through the normal content-script channel.
  Unrelated normal tabs continue to be preserved.

Jarvis's immediate Gemini Live startup, continuous logical session, internal
socket rollover, user-controlled stop, Smart Writing Gemini-audio path,
provider-authoritative billing, and the UI-thread ownership fix are unchanged.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

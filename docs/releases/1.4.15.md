# keyboard.wtf 1.4.15

keyboard.wtf 1.4.15 is a narrow Browser Automation routing and Smart Writing
quality update.

- Browser Automation now distinguishes discussion and brainstorming from an
  actual request to interact with a webpage. Selected-text explanations and
  idea exploration remain with normal Jarvis context, while explicit click,
  search, navigation, form, and other webpage actions still route to Browser
  Automation.
- When a browser task names a destination site and an interaction there, the
  planner establishes that destination before using page controls. An unrelated
  active page is no longer treated as the requested search or action context.
- Smart Writing adds a conservative final editorial check after Gemini output
  so meaningless speech fillers and accidental fragments do not leak into the
  finished writing. Quoted language, URLs, names, numbers, technical terms,
  meaning, and tone remain protected.

Smart Writing capture, Gemini audio, cursor and clipboard delivery, terminal
overlay lifecycle, billing, Raw Dictation, Gemini Live lifecycle, Screen
Reasoning, Chrome Helper 2.1.25, workflows and durable memory, file search,
authentication, updater security, and backend architecture are unchanged.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

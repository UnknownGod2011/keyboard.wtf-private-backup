# keyboard.wtf 1.4.15

keyboard.wtf 1.4.15 is a narrow Browser Automation grounding and Smart Writing
editorial-cleanup update.

- Browser Automation now distinguishes an actual webpage-interaction request
  from brainstorming, hypothetical product ideas, and selected-text discussion.
  Legitimate automatic browsing and explicit Browser Automation requests remain
  supported.
- When a browser task explicitly names a destination website or service, the
  planner establishes that destination before using page controls. An unrelated
  active page is no longer treated as the task's search or interaction context.
- Smart Writing performs a final conservative editorial check after Gemini and
  removes any standalone meaningless hesitation sounds that survived the model
  response. Quoted speech, URLs, uppercase abbreviations, names, technical
  details, meaning, and tone remain protected.

Smart Writing audio capture, Gemini routing, cursor insertion, clipboard
retention, lifecycle cleanup, and billing are unchanged. Gemini Live transport,
Screen Reasoning, workflows and durable memory, file search, Chrome Helper
2.1.25, authentication, billing math, usage retention, and updater security are
not redesigned by this patch.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

# keyboard.wtf 1.4.11

keyboard.wtf 1.4.11 is a focused correction for two real packaged-product
failures found after the 1.4.10 release.

- Smart Writing now keeps its explicit shortcut-to-finish behavior while also
  completing after a long final silence. Normal thinking pauses remain valid,
  but a finished recording no longer stays in Listening forever. The verified
  final Gemini text is placed on the clipboard before delivery, pasted only
  into the captured original target when that target is still current, and
  retained on the clipboard after a successful insertion. The Windows x64
  input structure used for the paste shortcut now has the complete native
  layout, fixing a packaged-build failure where Windows rejected all four
  Ctrl+V input events. Cancellation and replacement guards continue to prevent
  late pastes.
- Local file and folder tools now preserve an explicitly requested Desktop,
  Documents, Downloads, OneDrive, or concrete directory scope. Exact normalized
  names and shallow direct children outrank nested matches; spaces, underscores,
  hyphens, case, omitted extensions, and partial names remain supported. A
  learned or globally ranked result outside an explicit scope can no longer be
  opened as though it were inside that scope.

Jarvis Live, Screen Reasoning, Browser Helper 2.1.25, browser automation,
workflows, authentication, billing, pricing, reservations, and settlement are
not redesigned by this correction.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

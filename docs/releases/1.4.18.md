# keyboard.wtf 1.4.18

keyboard.wtf 1.4.18 is a narrow Jarvis Live accounting-lifecycle and paused
Browser Automation usability update.

- A healthy paid Live reservation now uses the authoritative long-session route
  lifetime plus bounded cleanup grace. Concurrent paid work can no longer
  reclaim a Live reservation merely because the physical session correctly
  outlives the retired short-session configuration.
- Browser Automation exposes structured `NeedsUserAction` details: the exact
  missing information or manual step, why it is needed, and whether the planner
  has established that it is safely optional.
- A relevant answer supplied through Jarvis resumes the same paused task. Task
  policy can skip demonstrably optional unavailable fields, while required,
  security-sensitive, payment, and irreversible dependencies remain protected.
- Explicit Browser Automation cancellation now reaches the existing one-task
  cancellation path even while paused, clears the intervention, and removes the
  progress UI without waiting for another model-selected control call.
- Normal conversation and ordinary browser/app commands remain separate from a
  paused browser task unless the turn clearly answers, corrects, skips, resumes,
  or cancels that task.
- The pricing page now uses a smaller product-focused hero and a compact FAQ.
  Existing sign-in, subscription, checkout, pricing, and account logic is
  unchanged.

Gemini Live audio/VAD/barge-in behavior, physical session rollover and
resumption, Smart Writing, Raw Dictation, billing prices and formulas,
workflows and durable memory, file search, Screen Reasoning, selected text,
Chrome Helper 2.1.25, and updater security remain unchanged.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

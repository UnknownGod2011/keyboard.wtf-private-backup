# keyboard.wtf 1.4.1

keyboard.wtf 1.4.1 is a reliability update for the production Windows app.

- Global shortcuts now show the shortcut Windows actually registered, reject
  inaccessible function keys, record physical key combinations directly, and
  preserve the previous working shortcut if a replacement conflicts.
- Shortcut changes and resets remain consistent across app restarts, including
  migration from inaccessible F13–F24 bindings.
- A server-revoked or expired desktop session now clears stale account data and
  blocks paid AI before another provider request can start.
- Recent usage and payment previews are bounded and scrollable while full
  server-owned financial and audit history remains intact.
- The website checks Chrome Helper readiness through a status-only handshake;
  it no longer treats installation alone as a live Jarvis connection.
- Chrome Helper 2.1.22 keeps the proven 2.1.21 native/content protocol for a
  compatible Store update without disrupting existing browser automation.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

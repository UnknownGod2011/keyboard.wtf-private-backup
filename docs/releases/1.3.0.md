# keyboard.wtf 1.3.0

keyboard.wtf 1.3.0 adds stable, opt-in browser automation for the user's
existing Chrome session while preserving the fast direct-open and search path
for simple commands.

- Chrome Helper 2.1.21 with exact Store and unpacked-fallback identities.
- Current-tab and same-window task execution with bounded recovery and concrete
  verification.
- Pause and cancel support, timer lifecycle updates, and Ctrl+Alt+X
  cancellation.
- First-task privacy disclosure and consent.
- Store-recommended extension setup plus a clearly labelled unpacked fallback.
- Safe single-instance Restart and registered Windows uninstall.
- Public privacy and support documentation.

The installer is not Authenticode-signed. Download it only from the official
keyboard.wtf GitHub Release, keyboardwtf.com, or the permanent keyboard-wtf.vercel.app fallback.

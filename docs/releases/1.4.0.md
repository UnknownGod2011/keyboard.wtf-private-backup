# keyboard.wtf 1.4.0

keyboard.wtf 1.4.0 introduces the production account and subscription experience
while preserving the fast Windows assistant, voice, selected-text, and existing-
Chrome automation workflows from the previous release.

- Sign in with Google once and use the same keyboard.wtf account on the website
  and Windows app.
- Jarvis Monthly is available for INR 999 per month with server-authoritative,
  provider-backed usage accounting and clear remaining-usage visibility.
- Account & Billing now shows the current plan, billing cycle, recent usage,
  payment history, devices, account switching, and renewal cancellation.
- Paid AI requests are authenticated, bounded, metered, and settled by the
  keyboard.wtf backend; provider credentials are never sent to the desktop.
- Browser automation continues to use the user's existing logged-in Chrome
  session through the keyboard.wtf Chrome Helper, with cancellation and manual
  intervention for sensitive steps.
- Human-friendly global shortcuts can be recorded, validated, reset, and safely
  changed without losing the previous working registration.
- Startup, Restart, uninstall, session persistence, signed update metadata, and
  package-hash verification have been hardened for normal Windows use.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

# keyboard.wtf 1.4.19

keyboard.wtf 1.4.19 is a narrow real-user reliability update for paused Browser
Automation tasks, selected context, farewell/cancellation ownership, ordered
content verification, and Pricing account presentation.

- A request that explicitly defers browser work until a later user-controlled
  page transition now retains the requested context without starting the action
  early. The later explicit continuation can adopt the fresh active tab while
  keeping one authoritative task.
- Fresh selected or copied context is attached to the browser planner only when
  it belongs to the current turn, or when the user explicitly asked to retain it
  for a later action. A stale unrelated selection cannot satisfy a new task.
- The planner receives the authoritative context before deciding that a form
  value is missing. Optional unknown values remain skippable only when the page
  and user policy allow it; required unknown values still pause safely. Natural
  answers naming one of those requested fields resume the same paused task. A
  page-wide clear/reset control cannot be inferred while correcting one field
  and requires an explicit user request. Complete form-field assignments also
  replace a stale restored value instead of repeatedly appending duplicates;
  explicit append/continue requests retain their additive behavior.
- Negated or control-only mentions of Browser Automation do not start a browser
  task; direct URL/app actions retain authoritative ownership.
- Explicit Browser Automation cancellation clears the intervention/progress UI,
  and a late result from cancelled in-flight work cannot replace the Cancelled
  terminal state.
- A clear Jarvis farewell remains locally authoritative before paused-task
  guidance or model output can consume the turn.
- Requests for latest/oldest/recent content by a named source must establish the
  source collection and verify that the final item identifies that publisher.
- Pricing waits for the existing Firebase session before rendering its CTA and
  aligns its plan, account notice, and compact FAQ to one responsive container.

Gemini Live lease/resumption, audio/VAD/barge-in, Smart Writing, Raw Dictation,
billing math and retention, workflows and durable memory, file search, Screen
Reasoning, Chrome Helper 2.1.25, and updater security are unchanged.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

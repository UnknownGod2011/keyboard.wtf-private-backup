# keyboard.wtf 1.4.5

keyboard.wtf 1.4.5 is a focused writing, selection, workflow, Settings, and
Chrome Helper reliability update.

- Smart Writing now sends the bounded captured speech audio through the
  authenticated keyboard.wtf backend so Gemini can understand the original
  words, names, terminology, pauses, and self-corrections. It returns only the
  intended writing; Raw Dictation remains local and unmetered.
- Explicit references to selected text force a fresh bounded capture first.
  Only a recent selection from the same foreground window can be used when a
  transient Windows capture fails.
- Saved workflows now take precedence over learned aliases, and deletion
  tombstones prevent obsolete workflow records or built-in fallbacks from
  unexpectedly returning after restart.
- Every supported keyboard.wtf Settings deep link now activates the matching
  visible section. Unqualified “open Settings” continues to mean Windows
  Settings.
- A healthy Chrome Helper command channel clears obsolete heartbeat errors.
  The desktop remains compatible with the published 2.1.21 protocol, while the
  2.1.23 Store package adds the same recovery cleanup in the extension.

Jarvis's immediate Gemini Live startup, continuous logical session, internal
socket rollover, user-controlled stop, provider-authoritative billing, and the
1.4.4 UI-thread ownership fix are unchanged.

The installer is not yet Authenticode-signed, so Windows may show an
unknown-publisher warning. Download it only from https://keyboardwtf.com or the
official keyboard.wtf GitHub Release.

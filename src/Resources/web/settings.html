Browser Automation

Smart page interaction in your existing logged-in Chrome. Direct opens and searches keep using Jarvis’s fast lightweight tools.

When you start a browser task, the Chrome Helper sends the controlled tab's URL/title, bounded visible page text, selected text, form/control state, and action receipts to the local keyboard.wtf app through Chrome Native Messaging. This can include personal information or communications present in the task you selected. When page understanding needs AI, keyboard.wtf sends the user request and a bounded task snapshot - plus a current-tab screenshot only for visual recovery - to the configured Gemini browser model.
The extension does not read cookies, password values, OTPs, authentication storage, or file contents. Password, CAPTCHA, file-upload, payment, checkout, banking, and account-security steps stay manual. Data is not sold, used for advertising, creditworthiness, or unrelated profiling. Compact local diagnostic metadata remains until you delete the app log or local app data; page text and screenshots are not written to browser-task history.

How to use Jarvis

Speak naturally. Jarvis uses fast direct actions when possible and browser automation only when a page must be read or changed.

  • Open things: “Open Chrome, my Downloads folder, and Spotify.”
  • Use Windows: “Open the camera” or ask for another supported Windows feature.
  • Understand your screen: select something and ask Jarvis to explain or analyse it.
  • Write faster: draft an email, message, note, or polished paragraph.
  • Automate a web page: ask Jarvis to fill a form, inspect a page, choose a visible option, or complete a multi-step browser task.
  • Remember preferences: “Remember my preferred meeting length is 30 minutes.”
  • Create routines: “Whenever I say initialize my setup, open these apps and websites.”
  • Use timers: start, check, pause, resume, or cancel a timer.
  • Just ask: Jarvis is available for normal questions and conversation too.
Browser automation pauses for passwords, OTPs, CAPTCHAs, payments, checkout, and account-security steps. You can cancel at any time with Ctrl+Alt+X.

What’s next

Features on the roadmap for keyboard.wtf.

  • Model library - browse and install Whisper sizes (Tiny / Base / Small / Medium / Large) and Vosk language packs from within the app.
  • Custom model URL - import any ggml Whisper or Vosk model by URL, useful for specialized domains and fine-tuned variants.
  • Vocabulary hints - add an initial prompt so Whisper transcribes names, jargon, and domain terms accurately.
  • Deeper app actions - add contact lookup and richer app-specific automation while keeping manual review for sends.
  • Transcript history - dial through recent transcripts on the device and re-send any of them without re-recording.

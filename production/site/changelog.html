Changelog

keyboard.wtf 1.4.5

Version 1.4.5 upgrades Smart Writing to understand the captured speech audio through the authenticated keyboard.wtf backend while keeping Raw Dictation local. It also refreshes explicitly requested selections, prevents deleted workflows from returning through stale mappings, synchronizes every Settings deep link with its visible section, and clears stale Chrome Helper errors after the real command channel recovers.

keyboard.wtf 1.4.4

Version 1.4.4 keeps the shared Jarvis, Smart Writing, and Dictation overlay on the application's UI thread even when status updates originate from background account, provider, or browser work. This prevents the raw Microsoft .NET window-handle error seen after an extended Jarvis validation run while preserving the 1.4.3 interaction behavior.

keyboard.wtf 1.4.3

Version 1.4.3 starts the real Gemini Live connection as soon as Jarvis is invoked, keeps one logical conversation and one visible Jarvis surface across recoverable socket rollovers, and prevents repeated deterministic actions. Smart Writing now has bounded latency and always leaves Polishing through one clear success, clipboard, cancellation, timeout, or error result. Browser close commands prefer the matching tab, and explicit user-approved URL aliases use the existing learned mappings.

keyboard.wtf 1.4.2

Version 1.4.2 improved expiring-account recovery, Settings restart recovery, microphone selection, Chrome Helper diagnostics, and Raw Dictation's local unmetered path.

keyboard.wtf 1.4.1

Version 1.4.1 improves global-shortcut recording, conflict handling, restart persistence, revoked-session recovery, bounded account history, and Chrome Helper connection reporting. It also hardens first-run speech-model setup, keeps Raw Dictation local and unmetered, and prevents Smart Writing from inserting a late result into the wrong window.

keyboard.wtf 1.4.0

Version 1.4.0 adds server-authoritative Google accounts, a ₹999 monthly plan, measured provider-backed usage, payment history, connected devices, subscription controls, and cryptographically verified desktop updates.

Jarvis foundation

Voice and text commands, selected-text assistance, screen understanding, timers, Windows actions, and existing-Chrome browser automation remain the core keyboard.wtf experience.

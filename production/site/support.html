Help with keyboard.wtf

Support

Sign in and account

Choose Sign in with Google on the Account page. For desktop pairing, begin sign-in from Jarvis, complete Google sign-in in your system browser, and approve that one-time connection. If the request expires, return to Jarvis and start again.

Chrome Helper

Install the Chrome Web Store helper recommended in Jarvis Settings and use Check connection. If Store installation is unavailable, Settings includes an unpacked fallback for troubleshooting. Do not enable both helper versions simultaneously.

Checking connection…A live handshake is required before Connected is shown.
Install from Chrome Web Store

Restart or uninstall

Use Restart in Jarvis Settings to safely release hotkeys and reconnect one new instance. Use Delete/Uninstall to launch the registered Windows uninstaller; it asks before removing keyboard.wtf and whether local settings and memories should be preserved.

Billing and devices

Payment status is confirmed by the server from Razorpay evidence and can be delayed briefly. Refresh Account & Billing if needed. Use Devices & sessions to revoke a desktop you no longer use.
